This project is a simple Spring Boot application used to demonstrate a **CSRF (Cross-Site Request Forgery)** attack with stateful authentication. After the user logs in, Spring Security creates a session and the browser stores a `JSESSIONID` cookie. The application contains a vulnerable `POST /account/change-email` endpoint, and CSRF protection is intentionally disabled. A separate attacker page sends a forged POST request to this endpoint, while the browser automatically includes the authenticated user's session cookie.

The attack works because the server sees a valid authenticated session and cannot distinguish the forged request from a legitimate one. When CSRF protection is enabled again, Spring Security requires a valid CSRF token for POST requests. Since the attacker page does not know this token, the forged request is rejected, usually with an HTTP `403 Forbidden` response.
